04 / FAQ

Questions,
answered.

What is Sportzfy TV?+

Sportzfy TV is presented here as a worldwide sports streaming app for Android and TV, with a sports-first interface for discovering events and channels.

Where do I get the latest APK?+

The primary APK button and every mirror button are loaded from config.json. Update the URL in the admin panel, export the config and deploy it to the same domain.

Can I change the version without editing the HTML?+

Yes. Set the version in the configuration panel. The landing page reads it dynamically and updates the hero, download section and metadata.

Can I add more mirror sites?+

Yes. Add as many mirror name/URL pairs as you need in the admin panel. They will appear automatically beneath the main download button.

Can I replace the screenshots?+

Yes. Put your image files in the assets folder and change the screenshot paths in the config JSON. The carousel will use the new list.

Does the admin page change the server JSON automatically?+

This version is intentionally static: it stores changes in the browser's localStorage and lets you export a new config.json. A server-side save endpoint would be required to overwrite the hosted JSON for every visitor.
